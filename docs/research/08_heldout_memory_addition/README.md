# 08 重み固定の保留タスク・メモリ追加

## 問い

LIBERO-90で学習したSkillNetの重みを固定したまま、LIBERO-Longの実演をメモリへ追加すると、追加実演に含めていないLong評価試行を救えるか。Goal実演を同数追加する対照と比べ、単なるメモリ容量増加とLong実演の内容を分ける。

## 結論（準備時点）

まだ学習・評価は実行していない。現行 `MemoryPi05` は通常Pi0の実装を継承しており、SkillNet-90 MoE checkpointとはそのまま復元・推論できない。互換性に必要な変更点と実行コストを整理した。指定のLIBERO-90 converterはRLDS/TFDS datasetを読む一方、ローカル指定先はHDF5ファイルの並びで、入力ローダーの確認も先に必要。

主比較では、各Longタスク50デモのうち5件/タスクを保留し、追加量を5・20・40件/タスクにする。50件/タスクは全デモを追加する上限条件で、デモ保留と同時には成立しないため補助条件として分ける。主張は「今回の追加学習に含めていないタスク」に限定し、事前学習全体で未見だったとは主張しない。
