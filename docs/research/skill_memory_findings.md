## 1. スキルの定義（ユーザー確認済み）

スキル = 場面に依存しない運動の型。場面との対応はメモリが受け持つ。個数は事前に決めない。

```
符号化（M1）：  (b, r) = Enc(A, s)     b：運動の型（12次元）、r：場面の細部（4次元）
               Â = Dec(b, r, s)        観測は見ない（見せると b が無視される）
               L = ||Â − A||² + β·KL(r) + λ·(相互共分散 + HSIC)(b, r)
スキル単位（M6）：機能的距離 D(b, b') = 同じ (r, s) で復号した行動の差
               ε = κ × 学習データでの D の中央値
               min_j D(b, c_j) ≤ ε なら単位 j に割り当て、そうでなければ保留
               保留の中で D ≤ ε でつながるまとまりが m 区間以上・e エピソード以上なら新しい単位に登録
               既存の単位と D ≤ ε なら登録せず統合。追加時は勾配で更新しない
```

## 4. 取り出したスキルから行動を仕上げる

```
学習：  アクションヘッド F_iii(x, f, s) を、劣化 x = Dec(b, r ~ N(0, I), s) から元の A を復元するよう学習
        （(iii) 学習した抽象化。細部 r だけをノイズに置き換え、運動の型 b は保つ）
推論：  b̂ = メモリ（クエリで top-1）
        x = Dec(b̂, ノイズ, s) に弱いホワイトノイズ t0 を足す → F_iii で仕上げる
比較：  RAGDP 型（取り出した完成行動 A に t0 のノイズを足して、通常の F で仕上げる。既存手法）
```

| 条件（H=25、各方式の最良 t0） | Split A（goal の既知クラス） | Split B（spatial） |
| --- | --- | --- |
| 通常（ノイズから） | 0.176 | 0.209 |
| RAGDP 型 | 0.159〜0.166 | 0.183〜0.204 |
| (iii) 学習した抽象化 | **0.145〜0.158** | **0.157〜0.180** |

| (iii) で正解の b を渡す（上限） | 0.050〜0.062 | 0.036〜0.062 |

- 取り出した中身は効いている（シャッフルで大きく悪化）。
- H=25 では、同じ取り出しで (iii) が RAGDP 型に全条件で勝つ（差 0.008〜0.03）。H=10 では五分五分。
- 上限との差が大きい。**ボトルネックは取り出し（正しい b を引くこと）**。
- 運動の型の保存：同じ b で r を変えても、運動ラベル（向き・回転・グリッパー）が 99.9% 一致する。

### 4.1 デノイズのステップ数

`denoise-step-sweep-20261027T172441Z-257810`。(iii) と RAGDP 型は、H=25 では**1ステップ**で、通常の F の10ステップと同等以上の誤差になった（Split A：(iii) 1ステップ 0.148〜0.159、通常10ステップ 0.176）。
ただし、行動の二乗誤差は平均的な行動を出すほど小さくなるので、ステップが少ないほど有利に見える。通常の F でも2ステップの方が10ステップより誤差が小さい。多峰性を保てているかは、この指標では分からない。
H=10 の Split B では、少ないステップで通常に届かない条件もある。先行研究（STEP など）でも、少ステップで足りるかはタスクによって大きく違う。

## 5. クエリ（取り出し）

- 旧キー（言語なしの VLM 特徴＋状態の PCA 最近傍）：見た目が似た区間を引き、別 suite の記憶からはランダムと同程度。
- クエリ専用の埋め込み（CLIP 型の対照学習）：画像（E_img）・状態（E_state）・サブタスク（E_sub）をそれぞれ埋め込んで連結し、h(b) と近づける。Split A で改善したが、Split B では旧キーと同程度。
- 入力を外す分析では、画像を外すと大きく悪化し、状態とサブタスクの寄与は小さかった。ただし画像入力に言語ありの特徴 f が入っており、**指示文が画像経由で漏れていた**。
- **同じ場面・違う指示の曖昧さ**（LIBERO-goal は10タスクが同じ場面を共有）：
  - エピソード初期のフレームで、言語ありの特徴（f＋k）からはタスクを 97.7% 当てられる。言語なしの特徴（k、手先カメラ）では 7.0%（ランダム 10%）。
  - 初期区間で同じタスクの記憶を引く率：f＋k 79.5% → k だけ 30.2%、手先カメラだけ 26.7%。k にサブタスク文または指示文を足すと 65.1%。
  - **画像だけのクエリでは、同じ場面の別タスクを引いてしまう。サブタスクや指示（言語）はクエリに必須**。
- サブタスク文（π0.5 の粒度、例 "pick the black bowl on the ramekin"）を単語埋め込みの平均で入れた比較では、一貫した改善はなかった。これは f 経由で指示文がすでに入っていたためと考えられ、言語なしの画像特徴で測り直す必要がある。

## 6. 行動空間の次元

`skill-dims-thresholds-20261027T172017Z-384277`（§1）。M1 のベース b を {4, 8, 12, 16, 24, 32} 次元、残差 r を {2, 4, 8} 次元で学習した（H=25、seed 0、Split A/B）。
文献の調査は `research-overnight-20261027T171157Z`（§2）。

| b（r=4） | 自分の b の誤差（A / B） | b の情報量（bits/区間、A / B） | スキル間の差 ÷ スキル内のばらつき（A / B） |
| ---: | ---: | ---: | ---: |
| 4 | 0.149 / 0.072 | 63 / 83 | 1.2 / 4.2 |
| 8 | 0.094 / 0.042 | 90 / 74 | 4.0 / 12.2 |
| 12 | 0.060 / 0.025 | 101 / 76 | 9.5 / 8.0 |
| 16 | 0.034 / 0.019 | 92 / 66 | 3.8 / 6.1 |
| 24 | 0.025 / 0.015 | 130 / 73 | 5.4 / 11.1 |
| 32 | 0.021 / 0.016 | 135 / 88 | 6.3 / 11.9 |

- **誤差は b=32 まで下がり続け、頭打ちがない。** 再構成の誤差だけでは次元を決められない。
- **残差 r が使われていない。** r を標準ノイズに置き換えても誤差の変化は 0.0001 以下で、r の情報量は 0.002〜0.009 bits/区間。行動チャンクの情報はすべて b が運んでいる。
  - したがって b は「場面に依存しない運動の型」ではなく、行動チャンクを丸ごと圧縮したコードに近い。§4 の「同じ b で r を変えても運動ラベルが 99.9% 一致」も、r が効いていないことの帰結で、場面への非依存の証拠にはならない。
- 単位の分離は次元に対して単調でない（A は b=12 で最大、B は b=8 と 24〜32 で高い）。単位数も次元とともには増えない（A 54〜70、B 62〜83）。
- 次元の選び方（文献の調査からの提案）：軽量モデルで、次を満たす最小の容量を選ぶ。(1) 相対軌道・回転・グリッパーの再構成が許容範囲に入る、(2) 同じ運動を別の場面へ b ごと移しても有効で、r だけでは運動を復号できない、(3) 新しいエピソードでも誤差・距離の尺度・単位の追加率が安定する、(4) b と r の情報量を別々に測り、どちらかに全情報が逃げていない。
- 判断：b=12・r=4 は作業点として維持する。ただし (2) と (4) が未達なので、r に場面の細部を担わせる学習（r の KL の重みを下げる、独立化の罰則を強める）と、場面をまたいだ b の移し替えの検証を先に行う。r が使われないままなら、b/r の分解は主張せず、b を「運動のコード」と呼ぶ。

## 7. スキル創出の閾値

`skill-dims-thresholds-20261027T172017Z-384277`（§2）。M6 の κ×m×e の120条件（各 split 60、seed 0）。文献の調査は `research-overnight-20261027T171157Z`（§3）。

基準（κ=0.1、m=10、e=3）：

| Split | 単位数（学習 → 新しい suite → LIBERO-10） | 新しい / 既知の運動の登録率（比） | 最後に保留に残った区間 | 分離 | 重複ペア |
| --- | --- | --- | --- | ---: | ---: |
| A | 70 → 111 → 158 | 11.8% / 4.1%（×2.9） | 551（1.6%） | 8.1 | 1.8% |
| B | 65 → 86 → 124 | 6.1% / 2.7%（×2.2） | 393（1.1%） | 7.8 | 2.0% |

学習データだけで κ を選ぶ3つの規則（エピソードを2分割した被覆の安定性、被覆率÷log₂(単位数+1)、単位数の増え方の飽和）：

| Split | 選ばれた κ | 単位数（学習 → 新 → LIBERO-10） | 新しい / 既知の登録率（比） | 重複ペア | 単位の中心から作る行動の誤差 |
| --- | ---: | --- | --- | ---: | ---: |
| A | 0.15（2規則）、0.30（1規則） | 44 → 72 → 97（κ=0.15） | 10.2% / 1.9%（×5.4） | 1.8% | 0.098（基準 0.093） |
| B | 0.30（3規則とも） | 13 → 18 → 18 | 4.4% / 1.1%（×4.1） | 2.6% | 0.073（基準 0.064） |

- **κ を大きくするほど、単位は少なくなり、新しい運動と既知の運動の区別（登録率の比）は良くなるが、単位の中心から作る行動の誤差は悪化する。** Split A で κ=0.30 にすると、単位は 18 → 25 → 28 まで減り、重複ペアは 7.7% に増える。
- 3つの規則は経験則で、split によって選ぶ κ が分かれた。**データだけから唯一の粒度を決める一般規則はない**（文献の調査の結論とも一致する）。外の基準として、許容する誤追加率や運動の再現誤差を決める必要がある。
- 閾値の決め方（文献の調査からの提案）：
  1. 表現・正規化・機能的距離を学習データだけで先に固定する。
  2. 学習エピソードを fit／selection／calibration に分ける（同じエピソードの隣接窓をまたがせない）。
  3. fit で単位を作り、calibration の各区間で最近傍の単位までの距離 S を測る。許容する誤警報率 α を事前に決め、S の分布の (1−α) 分位点を閾値にする（split conformal 型。α=0.01 には calibration が 99 以上必要。窓は独立ではないので、エピソードごとに1つの値に集約する）。
  4. 新規の候補はすぐ登録せず、保留して複数のエピソードで再出現したら登録する（M6 の現行の規則を残す）。m や e は文献から決まる定数ではないので、ストリームの順序を変えて較正する。
- 注意：区間単位の誤警報率 α と、最終的に登録された単位のうち誤った単位の割合は別の量。ストリームを長く流すほど、誤った単位は累積しうる。保留・統合・順序への依存は別に評価する。
- 判断：κ は「既知の運動の誤追加率」を事前に決めて較正する方式に切り替える。基準値の κ=0.1 は比較用に残す。seed 1・2 は未実行。
