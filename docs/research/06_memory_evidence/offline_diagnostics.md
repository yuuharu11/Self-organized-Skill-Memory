1. **運動開始の利点**：同じ軽量FPのノイズ開始・固定ノイズでの運動開始・類似度調整・運動経路の学習を、同じspatial評価で比較する。

3. **検索の限界**：厳密な単位一致率と、正解単位を与えた参考条件を並べる。最良の運動片・意味的なスキルの正解率とは区別する。
4. **何を保存するか**：同じFP・同じt0・同じ更新数で生系列と圧縮単位を比べ、追加なし/ありで結果が逆転することを示す。
5. **二経路の検討**：理想的な選択の余地と、実入力だけのルーターの結果を示す。新しい内部MoEを学習して有効性を示したとは書かない。
