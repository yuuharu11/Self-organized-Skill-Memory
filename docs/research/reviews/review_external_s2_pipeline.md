# 外部レビュー：S2 閉ループのパイプライン（2026-10-29）

対象は、LIBERO-Skill の閉ループで動かしている学習なし版。公開 SkillNet の重みは凍結し、LIBERO-90 から作ったスキルメモリ（0.5 秒の単位 57 個）から取り出した行動を出発点にして、途中の時刻 t0 からデノイズする。

```
q = π0.5 の VLM（画像, 指示文, 状態）の最終層を、トークンで平均したもの
上位 5 件 ← メモリの全エントリから、q とのコサイン類似度で
w = softmax(類似度 / 0.001)、同じ単位の重みを合計し、単位 k を 1 つ引く
b' ~ N(c_k, σ_k²)、a = Dec(b', 今の状態)
信頼度 = 1 − H(w) / log 5 → 較正の表で t0、n = max(2, round(10·t0))
x = (1 − t0)·a + t0·ε → 公開 SkillNet のアクションヘッドで t0 から 0 まで
```

## 採用する確認（安い順）

1. **キーの見直し（オフライン）**：全トークン平均の代わりに、指示文のトークンだけ、状態のトークンだけ、アクションヘッドに渡る直前のトークン、などを比べる。LIBERO-90 の保留分で、上位 1 件の類似度の広がりと、正しい単位を引けた割合を見る。
2. **b' を決定的にする（オフライン）**：b' = c_k と、上位エントリの b_i の重み付き平均を比べる。Dec(b', s) と、デモの行動との誤差を見る。
3. **t0 = 0（デノイズなし）の確認**：閉ループではなく、オフラインで a とデモの行動の誤差として測る。LIBERO-Skill にはデモがないので、LIBERO-90 の保留分を使う。
4. 1〜3 が通ってから、閉ループで t0 を固定した比較（t0 = 1、0.6、0.4）を 1〜2 タスクで行う。

## 追補 2（外部レビューの 3 回目）

基準の変更に同意を得た。追加で採用したもの：

- 単位の検索に、Macro Recall（単位ごとの正答率の単純平均）を足す。多数派の単位だけを当てて稼ぐ場合を除くため。
- 行動の誤差を 3 段の上限に分ける。A：自分の b を戻したもの（圧縮器の限界）。B：メモリ内の別のデモのうち、潜在空間で自分の b に最も近いものを戻したもの（検索が完璧な場合）。C：正しい単位の中心を戻したもの。B と C の差は、中心への丸めで失う分。B と実際の検索の差は、キーで詰められる分。

## キーの確認 2 回目（extension-v2.json（ローカル記録: `.skillnet-state/outputs/memory-pilot/key-check-20261029T151636Z/extension-v2.json`））

## 外部レビュー 4 回目への対応

- 平均を取った空間：38 mm は潜在空間での平均（b̄ を 1 回 Dec）。ただし重みは、温度 0.001 で距離から作っていた。中心化後は上位の差が大きいので、重みはほぼ one-hot で、実質は上位 1 件の b だった。温度 0.001〜0.1 と、潜在空間・行動空間の平均を比べる。
- t0 の較正は、データ点ごとに同じ初期ノイズを共有して、t0 = 0.2〜1.0 を対応比較する（ノイズ 3 本以上）。
- 「今の 5 試行の改善は、局所解からの脱出の偶然かもしれない」という指摘はそのとおりで、速報の数字は手法の効果として扱わない。
