## Goal and constraints
- Research idea (owner: Yuya Yamamoto): actions always originate from a retrieved skill; flow-matching denoising adapts it to the scene. Start x_t0 = (1−t0)·a + t0·ε, integrate frozen action head t0→0 in n = max(2, round(10·t0)) steps (openpi: t=1 noise, t=0 action). t0 and n are set by retrieval confidence. t0=1 = normal policy. Goal is generalization, not speed.
- Benchmark: LIBERO-Skill skill_obj_02–09 (zero-shot; memory built from LIBERO-90). Paper: SkillNet 44.5%, π0.5 28.5% (8-task mean, 50 trials/task).
- Measurement constraints (archived): preserve existing experiment outputs; GPU preallocation disabled; CPU thread limits applied; production runs used code snapshots. The earlier no-commit instruction applied during measurement and is superseded by the later publication request.

## Pipeline as evaluated (condition `anchor_v2`, code in skill_moe/skillnet/examples/memory_pilot/anchor_flow/)
```
memory  = 55,660 LIBERO-90 entries: key (π0.5 VLM final-layer mean over prefix tokens), b = Enc(10×32 chunk) ∈ R^12, raw chunk, 57 M6 units
query q = same VLM pooling on current obs; center by memory-key mean μ, L2-normalize (keys too)
top-5 by cosine (exclude same episode/init), w = softmax(sim/τ), τ=0.05
a       = Σ w_i Dec(b_i, s)            # "dec_each" (Ap); alternatives dec_latent (A), raw (R)
t0      = table(top-1 sim) with gate; n = max(2, round(10·t0)); public SkillNet head frozen
```
Policy weights are never updated. Steady-state query ≈3.2 s (key 1.9 s).

- Old S2 anchor (Gaussian sample around unit center, uncentered key, entropy confidence) was as bad as the zero action (endpoint 59 vs 61 mm); its closed-loop result ≈ normal policy (6 vs 6 discordant over 37 pairs).
- Gripper-segment skills (median 2.6 s, 11,017 segments), phase-aligned reuse of retrieved segment: worse than normal policy at t0≤0.4 (new tasks S1 +.064, S3 +.103 at t0=.2); verb match 64%. Motion type is right, geometry is not.

## Conclusion so far
Training-free anchoring with a frozen head does not help on new tasks; forcing the skill hurts. Oracle shows headroom (−39% on new tasks), so the missing pieces are (1) retrieving the right skill for unseen tasks and (2) adapting a retrieved skill to the scene, which the frozen head cannot do.
