# 09 実機タスクの設計（2026-11-05〜）

## 問い

ラベルなしで創発した運動の価値を示すには、実機でどのタスクを使い、どの運動を獲得して、どう組み合わせるのがよいか。

## 結論（提案、実験は未実施）

- 基本タスクで運動を獲得し、重みを固定して新しい運動を追加し、両方を未学習の順序でつなぐ、3段階の構成にする。
- 主評価は、組み合わせだけでなく、**追加した運動そのものと、それを含む組み合わせ**にする。
- 「開ける」の中に直線、円弧、横、ねじりがあるように、**動詞と動きがずれる**運動を選び、ラベルとの差を確かめられるようにする。
- 実演した物体と別の物体でも評価し、実演の再生と「型」の再利用を区別する。
- 提案手法の実機評価は、シミュレーションで基準を上回ってからにする。
