# スキルの作り方（2026-10-27 時点の暫定方針）

## 定義（ユーザー確認済み）

- スキルとは、場面に依存しない運動の型のこと。
- 場面との対応はメモリが受け持つ。メモリの項目は、キーが観測特徴、値がスキルのベース。
- スキルの個数は事前に決めない。k-means などで K を固定しない。初期化にも評価にも使わない。
- 取り出すときは1つに決めず、ソフトマックスの重みで複数をブレンドする。

## 表現（現状で最も良い M1）

- 区間は H=25 ステップ（約1.25秒）の 7 次元行動チャンク A と、固有感覚 s。
- Enc(A, s) から、ベース b（連続 12 次元、どんな運動か）と残差 r（4 次元、この場面での調整）を出す。
- b と r の独立化に、相互共分散と HSIC の罰則を使う。重みは 0.01〜0.1。r には KL をかけて容量を絞る。
- 復号は Â = Dec(b, r, s) で、観測を見ない。観測を見せると b が無視される。
- 観測特徴 f からは、Prior(f, s) が b と r を予測する。
- 実装は `skill_moe/skillnet/examples/emergent/light/methods/m1.py`。

## スキル単位の作り方（M6、検証中）

- 機能的距離 D(b, b') は、同じ (r, s) で復号した行動の差。尺度は ε = κ × 学習データでの D の中央値。
- 最も近い単位との距離 D が ε 以下なら、その単位に割り当てる。そうでなければ保留の場所にためる。
- 保留の中で、近い区間が m 個以上、別々のエピソード3つ以上から集まったら、新しい単位として登録する。既存の単位に近ければ統合する。
- 追加するときは、勾配での更新をせず、既存の中心も動かさない。
- 実装は `methods/m6.py`。

## 取り出し

- キーで上位 k 件の項目を取り、α = softmax(−距離 / T) で重みを付ける。
- ブレンドは、項目のベースを混ぜる方法と、単位の中心を混ぜる方法の2通りを比べている。

## 根拠

軽量版の小さな MLP での結果。H=25、乱数シード1つ。VLA 方策での効果は未確認。

- M1 は、新しい suite の再構成誤差が一番良い（0.09〜0.12）。
- 新しい運動の区間を当てる AUROC は 0.87。スキルを足した率は、新しい運動で約 7.5%、既知の運動で約 2%。
- VQ、FSQ、残差 VQ、辞書の方式は、表現力または区別の点で劣った。
- 既知の運動でも約 2% を誤って追加する。M6 の「繰り返し現れたら登録」は、これを抑えるためのもの。
