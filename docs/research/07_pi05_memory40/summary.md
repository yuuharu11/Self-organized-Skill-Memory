# π0.5 LIBERO-40：評価条件と結果の総括

記録日：2026-11-04

## 問いと範囲

この調査は、固定した公開 `pi05_libero` と、実演チャンクを検索して修正 Expert の開始下書きに使う構成を、LIBERO シミュレーションで評価したもの。現時点の閉ループ結果は学習範囲に含まれるタスクでの評価であり、未知タスクへの汎化を示すものではない。ここでいう「成功」はシミュレーションでのタスク成功を指す。

## オフライン検索と下書き

### 検索キーと行動の対応

共通オラクルで3,277 queryのうちEval 1,318行を評価。対応は、メモリ実演の正規化active-7行動MSEが閾値以下（主閾値 .01）になること。候補から同一タスクを除く主条件で、現行VLM grouped-MaxSim Top-1の対応率は3.64%、Top-1行動MSEは0.2355、query内Spearman(score, action-MSE)は−0.157。負の相関はスコア上位ほど距離が小さい方向だが、Top-1対応率は低い。wrist-onlyはTop-1 MSE .0989、対応率5.84%で現行特徴を上回ったが、オラクルには届かない。

このSpearmanは各query内のTop-64候補を比較した検索順位と真の実演行動MSEの相関。下の下書き診断にある「下書きMSEと生成後MSE」の相関とは、変数も評価単位も異なる。

先行Dev集計の「Top-1スコアとTop-1下書き誤差」のquery間Spearmanは約 +.10（想定と逆向き）だった。上記の−.157はEval queryごとのTop-64候補順位と真の実演行動MSEのquery内Spearmanである。母集団と相関対象が異なるため、符号を直接比較しない。

### 下書きと修正Expert

同一のEval行・固定ノイズで、`t0=.6` の通常π0.5は平均MSE .007306、中央値 .001645。ゼロ下書きは平均 .004904、正解bの下書きは .004486、VLM検索下書きは .004779。通常から正解b下書きまでの改善量に対し、ゼロ下書きが得た割合は `(.007306−.004904)/(.007306−.004486) ≈ .85`。一方、計画の定義 `G=(B−X)/(B−E)`（B=ゼロ下書き、E=正解b、X=候補）をVLM下書きに適用すると約.30で、VLM対zeroの差の95%区間は0をまたぐ。この比較は、修正Expertの追加学習の寄与と下書き内容の寄与を分ける診断であり、閉ループ成功率ではない。

`.6`での下書きMSEと生成後MSEの行単位Spearmanは、oracle .607、`bprior_direct` .552、VLM retrieved .385、bprior retrieved .510、shuffled .101、zero .133。oracle対zeroの最終MSE差は−.000417 [95% episode bootstrap CI −.000623, −.000229]。VLM retrieved対zeroは−.000124 [−.000382, +.000123]で区間が0をまたぐ。正解動作を用いた診断下書きには測定可能な差があった一方、現行検索下書きがゼロ下書きを上回る明確なオフライン差は確認できなかった。

### 信頼度ゲート

検索スコア境界はrun-01メモリスコアの分位点から、成功率を見る前に固定された。スコアは正解確率として校正された量ではない。

| スコア帯 | 適応条件の `t0` | fallback条件 |
|---|---:|---|
| `<.92968` | .6 | 通常π0.5へfallback |
| `.92968–<.94267` | .6 | .6 |
| `.94267–<.95002` | .4 | .4 |
| `≥.95002` | .2 | .2 |

適応条件の閉ループ結果は91/100、fallback条件は94/100（同じ100組で通常95/100）。低スコアfallbackは通常方策へ戻す運用を評価したもので、検索スコアの確率校正を示さない。今回の既知タスク・設定では、メモリ固有の改善を確認できていない。

## 解釈と未検証事項

**観測事実：** 現行VLMキーでは検索上位に行動の対応が十分集まらず、検索順位の相関も弱い。オフラインでは正しい下書きの有用性を測れたが、現行検索下書きとゼロ下書きの差は不確かだった。6つの閉ループ条件は共通100組で通常方策を上回る救済数を示さず、全条件で救済と悪化が混在した。

**未検証の仮説：** 方策と検索キーが似た観測情報に依存するため、方策の予測誤差が大きい状態では検索も同時に誤る可能性がある。これを今回の既知タスク評価から確認したとは言えない。

次の判定では、π0.5の予測誤差が大きい行や、通常方策が失敗する状態を対象に、メモリ内に有効な行動が存在するかと、実行時に選択できるかを分けて調べる。別途、LIBERO-Long等で追加学習に含めていないタスクへの効果を主張する場合も、その比較設計と学習範囲を明示する。
