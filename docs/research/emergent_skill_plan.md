# 創発スキルの方針

2026-10-25 時点の決定事項と未決事項。実装・評価はまだ行っていない。
[memory_pilot.md](memory_pilot.md) と [memory_pilot_gates.md](memory_pilot_gates.md) は、ラベル付きの公開チェックポイントを固定した事前判定であり、この文書はその次の段階の方針。

## 研究の芯

タスク・言語のラベルなしに創発した運動スキルを、メモリとして自律的に獲得していく機構。
スキル学習法そのものではなく、メモリとしての使い方と獲得の仕組みを新しく作る。
「忘れない」は主張の軸にしない（事前学習済みVLAは少量のリプレイでほぼ忘れないという報告がある。arXiv 2603.03818）。
主張は、勾配なしでその場で追加できること、タスクをまたいで再利用できること。

## 決定事項

## z の入れ場所と区間の長さ

**z の入れ場所**：ルーターと、action expert のトークン列への1トークン追加の両方に入れる版を本命にする。
ルーターのみの版（既存SkillNetと同じ経路）は比較対象にする。
理由：ルーターのみだと、z はエキスパートの選択を通じた間接的な経路でしか行動に効かず、prefixの情報だけで行動を出せるため z が無視される恐れがある。
z が無視されると最初の go/no-go 自体が判定できなくなるので、効く経路を本命にする。
追加するトークンは状態トークンと同じブロックに置き、自己アテンションの仕組みとマスクの規則は変えない。
G0の結果は、ルーターのみの版がどの程度効くかの参考にする。

**z が表す区間の長さ**：z は action expert が再構成する行動チャンクと同じ範囲から作る。H=25（LIBEROの20Hzで約1.25秒）を本命、H=10（SkillNet の LIBERO 学習設定と同じ、約0.5秒）を比較対象にする（2026-10-26 ユーザー確認）。
キーは推論ごと（`replan_steps=5` ごと）に作るので、隣り合う z の区間は重なる。
z の元にするのはデモ、または実際に実行された軌道だけにし、実行されなかった予測は登録しない。
当初の「50ステップ」はモデル設定の既定値を見た誤りだった。π0.5 の基本重みから学習し直すので H は選べる。

## ベースにする既存研究（2026-10-26 ユーザー確認）

Emergent Compositional Skills in MoE VLAs（ECS、arXiv 2607.20771）をベースにアレンジする。
ECS は π0 の action expert の FFN に MoE（LoRA エキスパート16個、チャンクごとに1回のルーティングを全層で共有）を入れ、ラベルなしでエキスパートの専門化を示した。
こちらの差分は、ルーターの入力に z を1段挟むこと。

```
ECS:    ルーター( VLM の平均, 固有感覚 )                         → エキスパートの混ぜ方
こちら: ルーター( z )   z = Prior(観測) または メモリの検索・ブレンド → エキスパートの混ぜ方
```

ECS の残した課題（スキル集合が固定、メモリなし、創発の証拠が定性的、タスク専用・未使用のエキスパート）を、
メモリによる追加・呼び出しと、創発の定量評価で扱う。SkillMemo と Optimus-R は比較対象にする。
ルーティング単位（トークンごと→チャンクごと）とエキスパートの形（FFN 4個→LoRA 16個）を ECS に合わせるかは、ECS のコード公開状況を確認してから決める。
