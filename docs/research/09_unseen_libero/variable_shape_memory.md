# 向きと大きさを除いてまとめる

## 結論

可変長の区間から向きと大きさを除いて DCT 3個にまとめると、同じ約20単位で誤差は .089 / .198 から .062 / .154 に下がった（全行 / 難しい行、ε=.005）。ただし、これは正解の向きと大きさを与えた上限である。

- **減ったのは移動だけで、回転はほとんど減っていない**。約20単位で移動は .092 から .038、回転は .115 から .107。今の向きは移動の方向から求めるので、回転は揃わない。
- **登録条件をなくすと大きく下がる**。捨てずに残すと460単位で .037 / .069。
- **約20単位では形の寄与は小さい**。同じく正解の向きと大きさを与えた直線2本（開閉）で .082 / .183 まで届く。
- **切り方による差は小さい**。固定10窓でも向きと大きさを除けば同程度で、可変長の差は単位数と選択回数が少ないことにある。

## 条件

- 対象とメモリは [固定長との比較](variable_memory_oracle.md) と同じ。未学習の評価619行（難しい134行）、LIBERO-40の400デモ、正解で代表を選ぶ。検索とデノイズはなし。
- 向き：物理空間で区間の総移動量を +x へ回す回転。回転の3軸にも同じ回転をかける。
- 大きさ：総移動量の大きさ（総移動量）、または動きのRMS（RMS）。総移動量は1区間の和が1になるので、長さを掛けて比べる。
- 代表：形の DCT 3個×6軸＋グリッパー。グリッパーは可変で1値、固定10窓では切替をまたぐので3値。
- 戻し方：代表の形に、問い合わせ自身の向きと大きさをかける。向きと大きさは区間ごとに計4値で、保存数には数えていない。
- まとめ方：M6。κ と登録条件は下表の全組み合わせ。「捨てない」は最小支持1、最小エピソード1。
- 確認：そのまま×固定10窓×まとめないは .0379 / .0858 で既存の DCT 3と一致。そのまま×ε=.005×κ=.1 は21単位 .0888 / .1978 で既存の結果と一致。

## 読むときの注意

- 正解の向きと大きさを与えた上限で、デノイズで合わせられるかは未確認。
- κ は評価行を見ずに決めた格子で、選んでいない。結論の行は単位数が近いものを評価後に並べた。多重比較の補正はしていない。
- 「捨てない」は1区間だけの単位も含む。動きを共有できているとは限らない。
- 総移動量がほぼ0の区間では向きが不安定になる。
- 評価は1回の固定シードで、Long は未実施。
