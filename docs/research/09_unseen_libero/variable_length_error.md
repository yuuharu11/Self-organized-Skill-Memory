# 可変長に切ったときの復元誤差

## 結論

デモの切り出し基準（[segmentation_demo](segmentation_demo/)）で切り、各区間をDCTで圧縮して戻すと、未学習タスクでの誤差は **ε でほぼ決まる**。ε=.005 と DCT 3個で全行 .0032、難しい行 .0033。固定10窓のDCT 3個（.0065 / .0092）より保存数が少なく、誤差も小さい。

ただし差の多くは、グリッパーの誤差が消えたことによる。移動と回転だけを比べると、固定窓のDCT 3個のほうが小さい。また、同じ区間数で等分した場合と比べると、誤差で切ることの効果は難しい行に限られる。全行では差がないか、ε が大きいとやや悪い。

ここでは各区間を自分自身から圧縮して戻しており、デノイズ、検索、区間どうしのまとめは入っていない。

## 条件

- 対象：未学習の評価619行（難しい134行）と Long 548行（難しい63行）。[draft_reconstruction.py](../../../skill_moe/skillnet/examples/memory_pilot/unseen_libero/draft_reconstruction.py) と同じ行、同じ指標（active7の正規化MSE）。
- 手順：行をエピソードの軌道へつなぎ、切り出し、区間ごとに移動と回転のDCTをk個とグリッパー1値を残して戻し、評価行の10窓を取り出す。
- 保存数：1区間あたり 6×k＋グリッパー1＋長さ1。下表は10フレームあたりの値。切り出しの統計は、開発用20本を含む未学習120本で数えた。
- 比較「等分」：エピソードごとに区間数とグリッパーでの切れ目を同じにして、残りは最長の区間を半分にしていく。保存数は同じで、切る位置だけが違う。
- 区間は k ごとに切り直している（kが大きいと長くなる）。

## 結果：未学習タスク

| 切り方 | 10フレームあたりの保存数 | 全行 | 難しい行 |
|---|---:|---:|---:|
| 可変 ε=.005, DCT 3 | 16.1 | .0032 | .0033 |
| 可変 ε=.01, DCT 3 | 12.9 | .0064 | .0068 |
| 可変 ε=.02, DCT 3 | 9.8 | .0126 | .0142 |
| 可変 ε=.04, DCT 3 | 8.0 | .0201 | .0253 |
| グリッパーでのみ切る, DCT 3 | 6.6 | .0293 | .0479 |
| 固定10窓 DCT 3 | 21 | .0065 | .0092 |
| 固定10窓 PCA 12 | 12 | .0176 | .0334 |
| 固定10窓 M1 b12 | 12 | .0105 | .0198 |
| 固定10窓 PCA 16 | 16 | .0087 | .0155 |
| 固定10窓 PCA 24 | 24 | .0033 | .0059 |

固定窓のDCT 3の全行 .0065 は、移動 .0019、回転 .0027、グリッパー .0314 を軸数で平均した値で、約7割がグリッパーによる。可変はグリッパーの切替で必ず切るのでこの誤差が0になる。移動と回転だけなら、可変 ε=.005 は .0038 / .0036 で、固定窓より大きい。

### 誤差で切る効果（DCT 3、可変−等分）

エピソード単位 bootstrap 5,000回の95%区間。多重比較の補正はしていない。負なら可変が小さい。

| ε | 未学習 全行 | 未学習 難しい行 | Long 全行 | Long 難しい行 |

| .01 | +.0001 [−.0006, +.0007] | −.0035 [−.0057, −.0014] | +.0008 [+.0004, +.0012] | −.0005 [−.0015, +.0004] |
| .02 | +.0013 [+.0005, +.0020] | −.0023 [−.0045, −.0004] | +.0021 [+.0005, +.0035] | +.0000 [−.0024, +.0020] |
| .04 | +.0029 [+.0019, +.0039] | +.0033 [+.0008, +.0055] | +.0007 [−.0009, +.0025] | −.0011 [−.0048, +.0026] |

## 結果：Long（DCT 3）

Longは1本が長く、同じ ε でも保存数は未学習の半分程度になる。

| 切り方 | 保存数 | 全行 | 難しい行 |
|---|---:|---:|---:|
| 可変 ε=.005 | 8.2 | .0034 | .0029 |
| 可変 ε=.01 | 6.5 | .0063 | .0057 |
| 可変 ε=.02 | 5.1 | .0119 | .0111 |
| 可変 ε=.04 | 3.9 | .0196 | .0212 |
| 固定10窓 DCT 3 | 21 | .0033 | .0215 |

## 読むときの注意

- ε は誤差の上限として切っているので、誤差が ε 以下に収まるのは基準そのものの結果で、発見ではない。見るべきは、そのときの保存数と、等分との差。
- 誤差はグリッパーを含む7軸平均、ε は移動と回転の6軸平均で、値は完全には対応しない。
- 区間の中ではグリッパーが一定なので、切替直前の遷移の値は表していない。
- デノイズで戻せるかは未確認。区間どうしをまとめたときの誤差も未確認。
