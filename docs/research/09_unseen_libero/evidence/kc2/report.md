# KC2：256次元クエリとグリッパーの同時学習

## 結論

選択条件は **q=i（GRUのみ）・負の二乗距離・τ=.03・λ=1・seed 3・epoch 16**。Dev の係数誤差は **57.784** で、KC1 の Dev 値に対する +5% 上限 **61.639** 以内だった。グリッパー閾値は **0.95**。指定ラベル `KC2-dot-Gdec` の閉ループ条件名を維持したが、Dev の係数誤差ゲートを満たして選ばれたスコア形式は dot ではなく負の二乗距離だった。

閉ループは LIBERO-90 **40/100**、LIBERO-10 **67/100**。LIBERO-10 は KC1 73/100、T5 A-topk-Gdec 81/100、π0.5 95/100 を下回った。LIBERO-90 は KC1 37/100、T5 34/100、π0.5 32/100を上回った。

## 選択とオフライン評価

144モデル（query 2種 × score 2種 × τ 3種 × λ 4種 × seed 3種）を最大16 epoch 学習した。選択は Dev v2 のみで行い、まず係数誤差を KC1 Dev×1.05 以下に制限し、その中でグリッパー切替の見逃し＋誤切替件数を最小化した。該当候補は27。Eval は選択後に一度だけ評価した。

選ばれた joint head の係数誤差は Dev / learned / unseen20 で **57.784 / 48.197 / 54.452**。

## 再現性・範囲

学習は KC1 と同じ LIBERO-40 学習 split。未学習行は20Hz unseen20、Dev v2 で選択し、推論入力は観測状態・行動履歴（iii の場合のみ VLM）に限定した。未来の正解・タスク ID・π0.5 出力は入力していない。KC1 保存係数と標準化統計を再利用した。

初回オフライン評価中間版は Dev 閾値のラベル符号化誤りを含んだため、`offline_results_invalid_dev_label_encoding.json` 等に無効版として保持した。最終の `offline_results.json` と `results.json` は ±1 ラベルで再計算した版。KC1 レポートの McNemar 勝者列も訂正し、テストで列向きを確認した。

学習・進捗時刻は `progress.log` にUTCで記録し、本報告の時刻表記はJST。
