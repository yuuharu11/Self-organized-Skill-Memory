## 分割と再現性

- episode-fold assignment seed: 4101; query seed: 3。fold ごとの件数と `(task,episode)→fold` は `manifest.json`。
- 各 fold は固定 KC1 (i, GRU-only, 標準化、τ=.03、16 epochs、query seed=3) で学習。heldout episode は検索メモリにも query optimizer にも含めていない。
- 保存物: `rows_fold0..4.npz` (top50 unit id/score、下書き、confidence、採点用誤差)、`rows_dev2.npz`、`rows_unseen20.npz`、`all_rows.npz`、`summary.json`。
- 信頼度特徴の生成関数 `confidence_from_scores` は正解行動・target coefficient を引数に取らない。`score_truth` は別関数。
- 実行時刻: 2026-11-20 20:09:44 JST。progress.log は UTC。
- CPU only。GPU は使用していない。
