# KQ2-CL：(iii) GRU×VLM クエリと (i) GRU クエリの閉ループ比較（Expert・t0 ヘッド・グリッパーデコーダ込み）

## 結論
- **LIBERO-90（未学習）では、提案 A（(iii) 検索＋t0 ヘッド＋グリッパーデコーダ＋π0.5 フォールバック）は 28/100 で、π0.5 の 32/100 に届かなかった**（A だけ成功 3／π0.5 だけ成功 7、p=.34）。t0 を定数 .15 にした A-const は 35/100 で、π0.5 と差はない（4／1、p=.38）。A は A-const に有意に負けた（0／7、p=.016）。
- **LIBERO-10（学習済み）では、メモリ経路はどれも π0.5 より大きく悪い。** π0.5 95/100 に対し、A 25（0／70）、A-const 68（0／27）、B 3（0／92）で、p はいずれも < 1e-7。
- **A 対 B（VLM の有無）は A が大きく上回った**：LIBERO-90 は 28 対 7（23／2、p<1e-4）、LIBERO-10 は 25 対 3（24／2）。**ただし、この差はクエリではなく t0 の差で説明できる。** 追加の切り分けとして、B の t0 を A-const と同じ .15 にした B-const（LIBERO-90）を回した。結果は 32/100 で、A-const 35 と差はない（8／5、p=.58）。B から B-const へは 3／28（p<1e-5）で大きく良くなった。
- **失敗の主因は、t0 写像が浅すぎること。** Dev v2 のオフライン MSE で選んだ写像は t0 = clip(0.5·√ê, .05, .2) になった（Dev の Expert 曲線は t0≈.1 が最良）。閉ループ内では ê がオフラインより小さくなる：(i) は中央値 .017（オフラインの未学習は .037）、(iii) は .049。このため t0 の中央値は B .065、A .103 まで下がり、ほぼ下書きをそのまま実行する状態になった（CL1 で下書きのまま実行した C2 は 3/100）。EKQ の E1a で見た「ループ内で ê が下がり、t0 が浅くなって悪化する」が、より強く再現した。(iii) は VLM のせいで自信が低い（ê が大きい）ので、t0 が深めに残り、フォールバックも多かった（24%）。A が B より良かったのはこのためで、VLM が良い単位を引いたからではない。
- **オフラインの順位は閉ループと逆になった。** 未学習 20 Hz の腕 MSE では (i) 系が明確に良い（head_t0 で (i) .050 対 (iii) .079）。閉ループでは、同じ t0（.15）なら (iii) と (i) は同程度で、ヘッドの t0 では (iii) が上だった。
- **学習済みの LIBERO-10 で π0.5 に大きく負ける**のは、π0.5 がこれらのデモを覚えているためと考える（オフラインの学習済み π0.5 腕 MSE は .0023）。メモリの単位は別エピソードの保存運動で、Expert を t0≈.15 で通しても、そのずれを直しきれない。A-const でも、π0.5 だけが成功した試行が 27、逆は 0 だった。
- **部品ごと**
  - Expert（K1:500）は、Dev v2 で EX3（G2:4000）をわずかに上回った（.0633 対 .0644）。ただし学習を進めると悪化し（5000 で .0650）、最初の checkpoint が選ばれた。
  - t0 ヘッドの Spearman は EKQ（.34〜.39）より高い：未学習 (iii) .47、(i) .60。予測中央値/真の中央値は .98〜1.0 で、オフラインでは過小評価がほぼ消えた。それでも閉ループの中では ê が下がる。
  - グリッパーデコーダ（未学習）：(iii) は見逃し .24・誤切替 .04、(i) は見逃し .78。比較として、EX3 Expert の出力（t0=.2）は見逃し .09・誤切替 .09、π0.5 は見逃し .07・誤切替 .11。q に VLM を含む (iii) のほうが、切替時刻を当てられる。A の失敗試行ではグリッパー切替が多い（成功 2.3 回、失敗 5.5 回）。

## 次の一手の候補（未実施）
