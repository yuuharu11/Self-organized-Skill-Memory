# 型の選び方：どの入力で運動の型を問い合わせるか（K1〜K4）

問い：推論時に手に入る入力（画像、指示文、状態、自分の実行行動の記録、π0.5 の内部特徴）だけで、メモリから正しい運動の型を選べるか。どの入力が未学習タスクで効くか。

## 結論

- **一番効くのは「直前10ステップの実行行動＋今の状態」（履歴）。** 未学習 LIBERO-90 で、random から oracle までの型誤差の差を 57〜63% 埋める。VLM の特徴（平均、トークンへの注目、中間層、Expert の層）を足しても、未学習では履歴だけを超えない。
- **VLM の特徴は、学習済みの場面に合わせ込まれている。** LIBERO-40 保留タスクの誤差は VLM を足すと .0069 → .0044 まで下がるが、未学習では下がらない。200エポックに延ばしても同じで、学習不足ではない。保留タスクで最良の層（Expert 15層）は未学習では 35% に落ち、保留タスクでの順位は未学習の順位を予測しない。
- **厳しい基準の top1 正解率は、どの方式でも 15〜29% の帯に収まる。** 同じ履歴入力でも学習設定で 20〜29% 揺れるので、方式間の差はほぼ誤差の範囲。画像を足すと下がる傾向がある。
- **型の価値はある。律速は向きと大きさ（θ）。** 正解の θ（θ*）で戻せば、履歴で選んだ型の6軸誤差は .058 で、π0.5（.192）よりずっと良い。推論時に手に入る θ では、その差がほぼ消える（[θ のデノイズと Expert での仕上げ](theta_flow.md)）。
- **比較には必ず「直前の行動を保つ」を入れる。** 6軸 MSE（全体 / 難しい行）で、直前の行動を保つ .114 / .201、ゼロ .144、全体平均 .134、π0.5 .192 / .307。動かない予測でも π0.5 より誤差が小さくなる指標なので、π0.5 との差だけで判断しない。

## 設定

- **候補：** LIBERO-40 のメモリ用デモから作った10フレームの型 2,049 個（向きと大きさを除いた C_vm_none）。LIBERO-40 の保留8タスク [2, 7, 12, 17, 22, 27, 32, 37] 由来を除いて 1,595 個。
- **学習：** LIBERO-40 の学習行 23,304 行。各行について、全候補を向きと大きさを最適に合わせた型誤差で並べ、その分布を目標にした listwise 学習。自タスク由来の候補は除く。クエリ（入力→MLP など）とキー（型→MLP）のコサインに温度をかけて softmax する。
- **選択：** 時点・温度・方式内の設定は LIBERO-40 保留タスクで選ぶ。K4 は未学習 Dev（LIBERO-90 のタスク 6, 7、113窓）で選んだ値も併記。
- **採点：** 未学習 LIBERO-90 の Eval 619窓（難しい行 134）。正解行動はここでだけ使う。
- **指標：**
  - 差の回収率：選んだ型の誤差が random（.0233）から oracle（.0045）までの差を何割埋めたか。
  - 厳しい top1：1位の候補が「oracle から random までの差の10%以内」に入った割合。
  - 行動 MSE：正規化した6軸の MSE。グリッパーは別扱い（下記）。

## K1：入力の総当たり

| 方式 | 入力 | 型誤差（全体 / 難しい行） | 差の回収率（全体 / 難しい行） |
|---|---|---:|---:|
| P5 履歴 | 直前10ステップの実行行動＋状態 | .0115 / .0215 | 63% / 45% |
| P6 トークン＋履歴 | 最終層トークン（画像128＋言語）の平均＋履歴＋状態 | .0117 / .0217 | 61% / 44% |
| P1 トークン注目 | 履歴＋状態から作った4本の問い合わせでトークンへ cross-attention | .0128 / .0219 | 56% |
| P2 中間層 | 6 / 10 / 14 / 15 / 16 / 17 層の V | .0127〜.0152 | 51〜56% |
| P3 Expert | Expert の隠れ状態 | .0152 / .0261 | 43% |
| P4 π0.5 出力 | π0.5 の行動チャンク | .0174 / .0276 | 32% |
| P0 平均 | 今の VLM 出力トークンの平均（従来） | .0174 / .0288 | 31% |
| P7 再構成ボトルネック | RL token 風に観測を再構成して凍結 | .0228 / .0288 | 3% |
| P7b 型教師ボトルネック | 同じボトルネックを型の InfoNCE で学習 | .0148 / .0239 | 45% |

P1 は履歴も使い、P6 はトークンを平均しているので、「トークンを平均しないことが効く」とは言えない（履歴と交絡）。

**グリッパー：** 型選択はグリッパーを見ていない。直前の実行行動のグリッパーを保つ規則（G1）にすると、グリッパー寄与は .0515（切替なしの行 .007、切替がある19%の行で .237）。開閉が一致する候補に絞る規則（G3）は効果がなかった。

## K2：層の総当たりと履歴の長さ

π0.5 の VLM 18層（prefix）と Expert の各層を、視覚だけの読み口として別々に学習した。保留タスクで選んだ後、未学習 Eval で採点した（`k2_unseen_layers.py`）。

- prefix は層ごとにばらつく（14〜56%）。最良は 17層 56%、次が 13層 47%。
- Expert は 0〜14層で 45〜55%、15〜17層で 27〜35%。
- 保留タスクで最良の Expert 15層は、未学習で 35%。
- K1 の履歴 63%、P1 の 57% を超える層はない。

## K3：クエリの改良

| 方式 | 厳しい top1（τ=.01 / .003） |
|---|---:|
| 履歴 | 24% / 29% |
| VLM 平均の連結 | 21% / 25% |
| 入力ごとのエンコーダ | 23% / 23% |
| ＋進捗（経過フレーム、切替回数、単位数） | 22% / 21% |
| トークン注目＋履歴＋進捗 | 22% / 20% |
| 10 / 14 / 16 層 | 16〜21% / 20〜27% |

τ を鋭くすると、正しいときと間違いのときで1位の確率に差が出る（.017 対 .006）。200エポックに延ばしても未学習の厳しい top1 は 16〜26% のまま（`results_e200.json`）。

## 読むときの注意

- すべてオフラインの型選択の評価で、閉ループの成功率ではない。閉ループは [DCT 可変長単位メモリの閉ループ評価](closed_loop_unit_memory.md)。
- 「未学習」は公開 LIBERO 微調整データ外という意味。
- θ* は採点側の上限で、推論時には使えない。
