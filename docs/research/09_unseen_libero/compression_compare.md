# 圧縮法の比較

## 結論

同じメモリ、同じまとめ方、同じ選び方で比べると、**圧縮法の差は小さい**。まとめないとき全行 .034〜.042、τ=.16 で .080〜.100 に収まり、誤差はまとめの強さでほぼ決まる。

保存する値の総数で見ると、1単位の値が少ない PCA 12 と M1 b12 が有利である。τ=.16 で PCA 12 は852値で .0839 / .1489、生は6,510値で .0796 / .1432。

可変は固定より全行で大きく、難しい行は同程度である。可変 PCA 12 は τ=.04 で7,956値、.0544 / .0958。固定 PCA 12 は10,056値、.0515 / .1019。

## 条件

- 問い合わせ側の正解は、単位の選択と採点だけに使う。検索とデノイズはなし。向きと大きさは単位に含む。
- メモリは LIBERO-40 の400デモ。PCA の基底は LIBERO-40 の学習行から作る。M1 は既存の codec で、Long を含む40タスクで学習済み。戻すときは問い合わせの状態を使う。
- まとめ方：復号した値どうしの平均二乗差が τ 以内の項目を覆う貪欲法。可変の PCA と生は32点に揃えた値で比べる。可変 DCT は DCT の値から求めるので、他と計算法が少し違う。
- 選び方：固定は10フレームごとに最も近い単位。可変は10フレームに1回の回数の中で全体の誤差が最小の並び。単位は保存された長さのまま当てる。
- 可変は ε=.005。「自分自身で戻す」はメモリを使わない圧縮だけの誤差で、切れ目もそのデモから決める。
- 区間推定はしていない。Long は未実施。
