# DCTの個数を変える

## 結論

個数を増やしても、メモリから単位を借りるときの誤差はほとんど変わらない。固定10窓は個数を増やすと少しだけ下がる（まとめないとき、3個 .0379 / .0858、5個 .0359 / .0838）。

可変は個数を増やすと区間が長くなるので、むしろ悪くなる（まとめないとき、3個 .0409 / .0795、5個 .0531 / .0904）。単位が多い分、2個が最も良い（4,869単位で .0335 / .0650）。τ=.08 では可変2個の244単位が .0655 / .1109 で、固定5個の359単位 .0609 / .1228 より全行は少し大きく、難しい行は小さい。

切れ目の基準はそれぞれの個数で計算している。可変で個数を固定したまま切り方だけ変えた比較はしていない。

## この DCT について

普通の直交 DCT（Type-II）を時間方向にかけ、各軸の低い周波数から順に k 個を残す。重みづけ、軸ごとの個数の調整、量子化はしていない。

## 条件

未学習の評価619行（難しい134行）、LIBERO-40の400デモ。問い合わせ側の正解は単位の選択と採点だけに使う。検索とデノイズはなし。向きと大きさは単位に含む。固定のグリッパーは k 個、可変は1個。可変は ε=.005。区間推定はしていない。Long は未実施。
