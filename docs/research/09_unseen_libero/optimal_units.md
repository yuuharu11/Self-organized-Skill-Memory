# 選ぶ回数を揃えた最適な並び

## 結論

選ぶ回数を揃えると、**どちらが良いかは選ぶ間隔で変わる**。

- **20フレームに1回**：可変 ε=.005 が固定10窓より良い。τ=.08 で可変269単位 .0747 / .1338、固定329単位 .0835 / .1502（伸縮あり）。固定は伸縮なしでは20フレームに届かない。
- **10フレームに1回**：全行では固定が良い。伸縮なしのまとめない場合は、難しい行だけ可変が良い（.0795、固定 .0858）。伸縮ありでは全行も難しい行も固定が良い。
- **5フレームに1回**：伸縮ありでは固定が良い。伸縮なしは固定が10フレームごとしか選べないので比較にならない。

時間のずれを許す誤差でも、傾向は変わらない。

## 条件

- 問い合わせ側の正解は、単位の選択と採点だけに使う。切れ目と向きと大きさには使わない。検索とデノイズはなし。
- 単位は向きと大きさを含めて保存した DCT 3個。
- 選び方：1デモの選択回数の上限を T÷間隔（切り上げ）とし、動的計画法で全体の誤差が最小の並びを求める。
- 伸縮：なし、または 0.5、0.75、1、1.5、2倍。物理空間で移動量を保つ。倍率は正解で選び、保存数には数えていない。固定にも同じ条件を与える。
- DTW：±5フレームの時間のずれを許し、合わせた後のフレーム誤差を行に集計する。
- 固定との差：同じまとめ水準、伸縮、間隔の固定10窓との行ごとの差。エピソード bootstrap の95%区間で、多重比較の補正はしていない。

## 読むときの注意

- 選択は正解を見た上限である。選ぶ回数が少ないことの実際の利点は、検索を入れないと分からない。
- まとめ水準が同じでも単位数は揃っていない（可変のほうが少ない）。
- 選択回数は上限で、実際の間隔は多少短くなる。
- 難しい行は固定の生の最良距離で決めているので、固定の生に不利に選ばれている。
- 条件数が多く、結論の行は結果を見てから選んだ。Long は未実施。
