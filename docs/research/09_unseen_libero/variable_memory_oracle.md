# 固定長のクラスタリングと可変長の比較

## 結論

LIBERO-40のメモリから未学習タスクの動きを戻すと、**まとめ後の誤差は固定長とほぼ同じで、単位数は半分程度だった**。可変長 ε=.005 の21単位が全行 .0888、難しい行 .1978で、これまでの固定10窓 M6（生の行動）の42単位は .0826 / .1986。全行では固定長のほうがわずかに小さく（差 +.0062、95%区間 +.0031〜+.0094）、難しい行では差がない（−.0008、−.0098〜+.0080）。

どちらも約 .09 / .20 で、区間を切るだけでは、まとめたことによる損失は減らなかった。

## 条件

- 対象：未学習タスクの評価619行（難しい134行）。指標はactive7の正規化MSE。検索とデノイズはなし。
- メモリ：LIBERO-40のメモリ行6,583行と同じデモ。固定長は既存の [oracle キャッシュ](oracle_results.md)。
- 可変長の代表：[切り出し基準](segmentation_demo/README.md)で切り、1区間に動きの DCT 3個×6軸とグリッパー1値の計19個を残す。長さで割り、問い合わせの長さへ伸縮して戻す。
- まとめ方：固定長と同じ M6 既定（κ=.1、最小支持10、最小エピソード3、代表は実在区間のmedoid）。距離は可変長ではこの19個で測る。単位数は揃えていない。
- 選び方：正解を見て最も近い代表を選ぶ。可変長の問い合わせは、未学習の動きを同じ ε で切った区間。固定長は10フレームごとに選ぶ。

- 登録されなかった区間の割合は可変で22〜64%（ε=.005で43%）。固定は23%（生、DCT 3）、45%（b12）。
- 可変は区間の中でグリッパーが一定なので、自分の切れ目で選ぶとグリッパーの誤差は0になる。移動と回転の誤差は同じ単位数帯の固定と同程度かやや大きい（ε=.005、M6：移動 .0921、回転 .1151。固定 生、M6：.0739、.1070）。
- 可変の代表を10フレームごとに選ぶと、切替をまたぐ窓のグリッパーを表せず悪化する（ε=.005、M6：.1251 / .2422）。

## 読むときの注意

- 単位数と選択回数が揃っていない。可変のほうが少ないので、同じ容量での優劣はこの表からは言えない。
- 可変の問い合わせは、正解の動きを使って切っている。切れ目も正解を見た上限である。
- 長さの違う代表を伸縮するとき、1フレームの行動値は保つ。行動は移動量なので、伸ばすと総移動量が変わる。
- 難しい行は固定の生の最良距離で決めたので、固定の生に不利に選ばれている。難しい行の差は小さく見積もって読む。
- 比較の区間は同じまとめ水準の固定の生との差で、多重比較の補正はしていない。Long は未実施。
