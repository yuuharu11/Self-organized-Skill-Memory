# 圧縮表現から始めるデノイズ

## 結論

最終チェックは**不合格**。主表の10条件のMSEと区間は独立再計算で一致し、行漏洩・自タスク除外・Dev以外での選択の問題は見つからなかった。ただし `C-rand-08` は平均単位長が比較対象 `C-vm-08` の5.17フレームに対して14.45フレームで、判定②の比較に長さの交絡がある。この条件を使った「形の選択がランダムよりよい」という結論は採用しない。A/Bの自己下書きとの比較は利用できる。

開発2タスクで選んだ圧縮下書き条件では、白色ノイズ `A-vm-none` が全Eval .0335 / hard .0694、下書き .0351 / .0717だった。追加の低周波条件は白色ノイズを上回らず、k=3の代表条件で低周波−白色の差は全Eval +.00112 `[+.00097,+.00129]`、hard +.00233 `[+.00190,+.00279]`。これは検索・閉ループ成功率の検証ではなく、正解で単位を選ぶオフライン上限診断である。

## 条件

- LIBERO-40の6,583窓から、訓練23,304行、Dev 113行（タスク6,7）、未学習Eval 619行（10タスク）、難しい行134行を使用。難しい行は固定した生メモリ距離しきい値 .0444191463 で定義。
- 候補単位は各Eval行の正解に最も近いものを選ぶ。正解は単位選択・採点・Devでの重み/t0選択に限って使い、区間、圧縮、下書きの姿勢、学習には使わない。
- Expertは通常action expertから初期化し、指定trainable filter、AdamW、最大4,000更新。重みとt0はDevで選び固定。表は選ばれた重みとt0のEval値。
- 低周波は Claude が追加実装した条件。長さ10の直交DCT-IIでノイズを最初のk係数に射影し、`√(10/k)` 倍する。全32次元へ同じ操作を行う。白色Aと同じ下書き・行・学習条件を用い、Devで比較した。

### DCT低周波ノイズ

低周波ノイズ条件も、Devで選んだ全設定で白色ノイズ条件よりEval MSEが大きかった。`L-vm-none-k3` は低周波 .03462 / .07172、白色A .03349 / .06939。差（低周波−白色）は全Eval +.00112 `[+.00097,+.00129]`、hard +.00233 `[+.00190,+.00279]`。`k3-wide` は全 +.00093 `[+.00075,+.00113]`、hard +.00232 `[+.00181,+.00289]`。`k5` は全 +.00056 `[+.00047,+.00066]`、hard +.00131 `[+.00108,+.00156]`。別の下書き群でも `L-vm-08-k3` は全 +.00070、hard +.00112、`L-raw-k3` は全 +.00092、hard +.00146。

ノイズを最初の3/10個のDCT係数だけに射影した検査では、高周波エネルギー比は約 `3.2×10⁻¹⁵`。残る差は、下書き誤差が低周波に偏るかどうかではなく、低周波に制限したノイズがこの評価条件で白色ノイズより有利でなかったことを示す。checkerは「合格」、reviewerは「妥当」と判定した。checkerは主表・区間の独立再計算と白色比較を確認し、reviewerはDCT射影・スケーリング・同一の学習/評価経路を確認した。22テストが通過。元GPU実行のノイズ配列は保存されておらず、スペクトル値は固定seedから再構成したノイズでの確認である。

## 読むときの注意

- 正解で単位を選んでいるため、検索可能性を示さない。成功率や閉ループ動作の主張でもない。
- 未学習の対象は公開LIBERO微調整スプリット外という意味で、pi05_baseを含む全事前学習履歴から未学習とは限らない。
- 固定10タスク・単一学習seedの評価で、bootstrap区間はepisode変動のみを表す。
- 低周波と白色の比較は今回のノイズ射影、k、下書き、分割に限定される。
- C-randの比較は長さ交絡があるため、判定②には使えない。該当する数値は記録として残すが、解釈しない。
