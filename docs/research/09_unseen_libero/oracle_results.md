# 表現ごとのoracle下書きとデノイズ

## 結論

17条件すべてでDev上に選んだcheckpointは評価できた。未学習Evalでは、正解から選んだ下書きが通常π0.5より小さいMSEを持つ条件はあるが、どの表現も、選ばれたt0=.2の生成後MSEは下書きMSEより大きかった。したがって、この表は検索器の性能を示さず、正解で候補を選ぶ上限診断である。

## 条件

LIBERO-40メモリ6,583窓から、未学習10タスクの619行（難しい134行）を評価。候補は評価行の正解行動に最も近いメモリ単位。checkpointとt0は別の未学習2タスク上のDevで選び、Evalの重み選択には使わない。下書きと最終値はactive7正規化行動MSE、全Eval / hard。

`none` は単位統合なし、`m6default` はM6で統合した候補。全条件の選択t0は.2。

## 読むときの注意

- **b12 M6のシャッフル対照は不公平とレビューされた。** `b12_m6default` のshuffle行は結論・方式間比較に使わない。この表は各条件のprimary下書きだけを載せている。
- oracleは行動正解を用いて候補を選ぶ。実行時に使える検索性能ではない。
- M6条件では代表単位の下書きを使う。単位数・支持条件などの詳細は実行結果の `oracle-01` データを参照。
- 評価は行動誤差であり、閉ループ成功率ではない。未学習とは公開LIBERO微調整スプリット外を指し、全事前学習履歴外を意味しない。

## 再現

入力・各条件の予測は `.skillnet-state/outputs/memory-pilot/unseen-libero/oracle-01/` に保存されている。各 `predictions/<condition>/result.json` にDevで選ばれたcheckpoint、曲線、対比較があり、`eval_rows.npz` に行ごとの予測がある。
